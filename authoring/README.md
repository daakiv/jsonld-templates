# Authoring

Metadata **authoring** workflows for the [Gaia Catalog](https://github.com/OHDSI/gaiaCatalog)
and OHDSI GIS metadata pipeline — how structured metadata is captured and turned
into machine-readable, FAIR-aligned JSON-LD.

| Folder | Purpose |
| ------ | ------- |
| `kobotoolbox/` | The KoboToolbox / XLSForm authoring workflow: capture metadata in Kobo, map it with a reusable SSSOM crosswalk, and transform it into Schema.org / Science-on-Schema.org JSON-LD. See its [README](kobotoolbox/README.md). |

Each subfolder contains its own `README.md` with detailed setup and usage notes.
